Questions from the Ministry textbook

Worked example — True or false (p. 34)
True / False

HTTPS communication uses both public-key cryptography and common-key cryptography.

True. Public-key mechanisms support authentication and safe session-key agreement; common-key cryptography protects the session data.
True / False

HTTPS exchanges all data using public-key cryptography.

False. Public-key cryptography would be slow for all data; shared common/session keys protect the data efficiently.
True / False

Two-factor authentication (2FA) uses two independent factors from different categories.

True. The categories are knowledge, possession and biometric factors.
True / False

Setting two passwords is an example of 2FA.

False. Both passwords are knowledge factors, so they are not two independent factor categories.
Matching

Match each need to the correct technology: (a) prevent third parties from reading communication content; (b) check that a signed message was not changed and comes from the claimed signer; (c) verify that the communication partner is genuine.

Answers: (a) Encryption; (b) Digital signature; (c) Digital certificate.
Try — textbook questions (p. 35)
Short answer

What role do a digital certificate and public-key mechanisms play when starting a secure TLS connection?

Model answer: The certificate helps the browser verify the server’s identity and domain name. Public-key mechanisms support authentication and safe agreement on shared secrets/session keys.
Short answer

Which cryptographic method protects session data after session keys have been established?

Common-key (symmetric-key) cryptography. It protects session data quickly and efficiently.
Essay question

Briefly explain how HTTPS uses certificates and public-key mechanisms to start a secure connection, then uses symmetric session keys to protect data.

Model answer: HTTPS runs over TLS. The browser checks the digital certificate and server identity; public-key mechanisms authenticate the server and safely establish shared session secrets. Afterwards, symmetric session keys encrypt the data because symmetric encryption is much faster for large amounts of communication.
Classification

Classify the authentication pairs: (a) password + one-time password; (b) password + fingerprint; (c) password + SMS authentication; (d) face recognition + smart card. Use: knowledge + possession; knowledge + biometric; biometric + possession.

Answers: (a) knowledge + possession; (b) knowledge + biometric; (c) knowledge + possession; (d) biometric + possession.
Multiple choice

Which statement is NOT an appropriate description of security technologies?

  1. Encryption prevents third parties from reading communication content.
  2. Digital signatures improve communication speed.
  3. Digital certificates verify that the communication partner is genuine.
  4. Combining security technologies can address different threats.
Answer: B. A digital signature supports integrity, signer identity and non-repudiation when needed; it does not improve speed.
Exam-style question · 6 marks

Explain why TLS uses public-key mechanisms for authentication and secure session-key agreement, then uses symmetric encryption to protect session data.

Model answer: Public-key mechanisms allow the browser to verify the server and safely agree on session secrets without exposing them. Encrypting all data with public-key cryptography would be slow. Therefore, after the session keys are created, symmetric encryption protects the data quickly and efficiently.

Performance tasks and homework
Essay questionp. 30

Explain how HTTPS protects communication and the role of TLS.

Model answer: HTTPS is HTTP over TLS. TLS encrypts data to protect confidentiality, supports integrity checks against tampering, and verifies the server’s identity through its digital certificate. This reduces eavesdropping, tampering and impersonation risks.
Essay questionp. 30

Distinguish the roles of symmetric encryption and public-key encryption in HTTPS.

Model answer: Public-key mechanisms are used for authentication and safe agreement on session secrets. Symmetric encryption is then used to protect session data quickly.
MCQp. 30

Which technology is mainly used to encrypt session data quickly and efficiently after the TLS handshake?

  1. Public-key cryptography
  2. Symmetric cryptography
  3. Digital signature
  4. Digital certificate
Answer: B — symmetric cryptography.
MCQp. 30

What are the steps called that establish a secure connection and verify the server and domain name through HTTPS?

  1. TLS handshake
  2. Digital signature
  3. Two-factor authentication
  4. Symmetric encryption
Answer: A — TLS handshake.
Essay questionp. 30

What is 2FA and how does a second independent factor reduce unauthorized access?

Model answer: 2FA uses two independent factors from different categories, for example a password (knowledge) and a one-time code sent to a phone (possession). If a password is leaked, the attacker still cannot log in without the second factor.
Essay questionp. 30

State the difference between 2FA and MFA.

Model answer: 2FA uses exactly two independent factors from different categories. MFA uses two or more different factors from knowledge, possession and biometric categories; therefore, 2FA is a form of MFA.

(2) MFA means using one password / two or more factors from different categories / fingerprint only. (3) The browser verifies the server and domain using a digital certificate / signature / 2FA. (4) The technology that detects tampering and supports non-repudiation is a digital signature / symmetric encryption / TLS handshake.

Answers: (1) knowledge + possession. (2) two or more factors from different categories. (3) digital certificate. (4) digital signature.
Essay questionp. 32

Explain how encryption, certificates and 2FA are combined when buying from an online store.

Model answer: HTTPS/TLS encrypts the connection and protects data in transit. The browser checks the digital certificate and domain to verify the server. 2FA reduces unauthorized logins, and a digital signature may be used when integrity and signer evidence are needed for particular data.

Password + OTP phone / password + fingerprint / password + second secret password / password + authenticator-app code. (3) HTTPS is HTTP over TLS / FTP / DNS / SMTP. (4) The three MFA categories are knowledge, possession and biometric / speed, efficiency and cost / public key, private key and password.

Answers: (1) Encryption. (2) Password + a second secret password. (3) HTTPS. (4) Knowledge, possession and biometric factors.
Model questionpp. 32–35

“Secure online communication and services depend on combining encryption and authentication, not on one technology only.” Discuss this statement.

Model answer: Each technology covers a different risk: encryption prevents reading, certificates verify server identity, digital signatures support integrity and non-repudiation, and 2FA reduces unauthorized login. Combining these layers addresses eavesdropping, tampering, impersonation and account takeover more effectively than a single technology, but it does not guarantee absolute protection.

Quick key facts

HTTPS / TLS

Certificate and public-key mechanisms: authentication and safe session-key agreement. Symmetric encryption: fast session-data protection.

Encryption

Prevents third parties from reading communication content.

Digital signature

Supports data integrity, signer identity and non-repudiation when needed.

Digital certificate

Helps the browser verify the server’s identity and domain name.

2FA / MFA

Use independent factors from knowledge, possession and biometric categories. Two passwords are not 2FA.
